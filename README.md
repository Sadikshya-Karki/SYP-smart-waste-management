# 🏙️ SYP - Smart Waste Management System

## 📌 Project Overview
This project is a full-stack **Smart Waste Management System** built as a Second Year Project (SYP).

The goal is to digitize and streamline municipal waste management operations by connecting citizens, workers, and admins through a single platform.

---

## 📊 Key Objectives
- Allow citizens to report waste and request services
- Assign and manage worker tasks efficiently
- Enable admin to oversee all operations
- Track requests and monitor progress in real time
- Build a role-based interactive web application

---

## 👥 User Roles
- **Admin** — Manage citizens, workers, requests and municipality services
- **Citizen** — Report waste, request dustbins, track requests, view leaderboard
- **Worker** — View tasks, manage pickups, contact admin

---

## 🛠️ Tech Stack
- **Frontend:** React, Vite, JSX, CSS
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Auth:** JWT, Google Auth
